# Printed parts

The [original design archive](original-designs/README.md) contains historical Prusa i3 single-frame and Greg/Wade STL/SCAD files with pinned provenance. Use the [original printed-parts catalogue](original-designs/Original-Printed-Parts.md) to find a model by assembly role, or the [small extruder gear](original-designs/Small-Extruder-Gear.md) page for the Stage H candidate.

The published sets are preserved locally, but exact compatibility with every recovered component remains under verification. Original downloads stay unchanged; project adaptations, print settings and fit results must be recorded separately.

New parts will be published, whenever possible, as editable CAD source files together with STEP, STL and reference 3MF projects.
