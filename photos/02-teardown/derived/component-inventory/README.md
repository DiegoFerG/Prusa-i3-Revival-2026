## Privacy / security processing

Each JPEG was decoded and re-encoded from pixel data only. EXIF, GPS, camera/device, XMP and other source metadata were intentionally omitted. Image orientation was applied before metadata removal. No content retouching or generative editing was performed.

These files are therefore **derived documentation images**, not byte-for-byte forensic originals.

## Manifest

`manifest.csv` maps each repository filename to the working-session filename, component ID where assigned, current description, SHA-256, byte count and privacy processing.

`SHA256SUMS.txt` contains checksums for all 69 derivative JPEGs plus the manifest itself.

Component IDs are working inventory identifiers. Photo IDs and filenames remain the stable evidence references even if a component description is later refined.
