# Cleaned component inventory photos — 13 September 2026

This directory contains public-repository derivatives captured during **Stage 01 — Teardown and assessment** while components were being cleaned, measured and catalogued.

## Privacy / security processing

Each JPEG was decoded and re-encoded from pixel data only. EXIF, GPS, camera/device, XMP and other source metadata were intentionally omitted. Image orientation was applied before metadata removal. No content retouching or generative editing was performed.

These files are therefore **derived documentation images**, not byte-for-byte forensic originals, and are intentionally stored under `photos/02-teardown/derived/` rather than `originals/`.

## Naming

The files continue the teardown archive sequence from `TD-20260913-160` through `TD-20260913-181` and use English-only filenames in accordance with repository policy.

`manifest.csv` maps each repository filename to the filename supplied in the working session and to the current component inventory ID when one has already been assigned.

`SHA256SUMS.txt` contains checksums for integrity verification.
