# Stage 01 — Teardown photo archive

This directory contains the photographic evidence collected during **Stage 01 — Teardown and assessment** of Prusa i3 Revival 2026.

## Batch 01 — Pre-teardown baseline

The photographs in `originals/` were captured on **13 September 2026** immediately before and at the start of the controlled teardown session. They document the workbench preparation, installed mechanics, wiring, electronics, PSU, LCD, motion system, extruder and hotend before components are removed.

The sequence is intentionally separate from the frozen Stage 00 archaeology / as-found archive.

## Naming convention

`TD-YYYYMMDD-NNN-subsystem-description.jpg`

Where:
- `TD` = Teardown
- `YYYYMMDD` = capture date
- `NNN` = chronological sequence within the teardown archive
- `subsystem-description` = concise English description of the photographed subject

## Preservation policy

Files in `originals/` are photographic evidence. Do not intentionally edit, overwrite, rotate destructively or recompress them.

Crops, annotations, web-optimised images, comparison images and other derivatives should be stored separately in a future `derived/` directory.

## Language and path convention

Repository directory names, filenames, document filenames and repository documentation should use **English**. Human-facing blog content may remain bilingual as defined by the project roadmap.

See `INDEX.md` for the per-photo catalogue for this batch.
