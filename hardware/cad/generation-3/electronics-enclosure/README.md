# Generation 3 Electronics Enclosure CAD

Parametric CAD for the Prusa i3 Revival 2026 Generation 3 electronics enclosure.

## Directories

- fusion360/ - Editable Fusion 360 source files
- step/ - Neutral STEP exports
- stl/ - Printable STL exports
- drawings/ - Technical drawings and PDFs
- renders/ - Design renders and reference images

Official vendor CAD remains under:
hardware/reference/bigtreetech/
