# Electronics Bench Platform

## Proyecto
Prusa i3 Revival 2026 - Generacion 3

## Objetivo
Plataforma impresa para organizar la electronica
durante las pruebas y el desarrollo de la impresora.

## Componentes iniciales
- BIGTREETECH Manta M8P V2.0
- BIGTREETECH CEB (CAN Expansion Board)
- EBB36/42 GEN2 USB Adapter

## Requisitos mecanicos
- Superficie superior completamente lisa.
- Sin agujeros pasantes ni salientes superiores.
- Patas integradas en la cara inferior.
- Separadores cilindricos independientes, pegados.
- Fijacion desmontable de las placas mediante tornillos.
- Espacio reservado para futuras ampliaciones.
- Dimensiones exteriores pendientes de definir.
- Compatibilidad con impresion FDM en Bambu Lab P1S.

## Organizacion
- fusion360/: modelos CAD nativos editables.
- exports/: archivos de fabricacion STEP y 3MF.
- references/: referencias propias del diseno.
