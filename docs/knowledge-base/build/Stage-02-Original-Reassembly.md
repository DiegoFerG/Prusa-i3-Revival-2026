## Completion gate

Use section 14 of the [source manual](../../02-reassembly/original-reassembly-manual.md) for the final mechanical checks. Record measured alignment, free movement and component condition before changing the overall Stage 02 status.

Section 15 defines component states: `REUSE`, `RESTORE`, `REPLACE`, `REDESIGN` and `ARCHIVE`. Keep these separate from this navigation page's workflow status.
