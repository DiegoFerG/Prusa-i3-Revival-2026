# Manual Stage H — Wade-style geared extruder and legacy 3 mm hotend

This is a navigation page within Roadmap Stage 02. The authoritative procedure is section 11 of the [original reassembly manual](../../02-reassembly/original-reassembly-manual.md).

Reconstruct the geared extruder and hotend mechanically using the source manual. The captive heater cartridge and unconfirmed thermistor remain documented limitations, and no heater is energized.
