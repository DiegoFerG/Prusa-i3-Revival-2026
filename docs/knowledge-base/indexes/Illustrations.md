When an illustration is added, link its actual file and editable source here, identify its subject and source evidence, and record creator, license and any generative or interpretive changes. Check [historical-source licenses](../../02-reassembly/historical-manuals/LICENSES.md) before importing reference artwork. Keep observed geometry separate from illustrative reconstruction and future design concepts.
