# Redistribution notes

The files stored in this directory are preserved as historical source material. Each file retains its original contents and is accompanied by source and license information in `../historical-references.md`.

- RepRap Magazine Issue 2: archive reports the original license as **CC BY-NC-ND**. The PDF is stored unchanged.
- Clone Wars / RepRap `Prusai3boxframeconstruction.pdf`: the document itself states **GFDL**. The PDF is stored unchanged.
- Josef Prusa `Prusa3` documentation: upstream repository states **GPLv3**. Selected source documentation is stored with upstream attribution.

Where a source did not present sufficiently clear redistribution terms, this repository records only a link and description rather than copying the work.
