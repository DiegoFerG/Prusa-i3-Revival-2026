# Redistribution notes

This directory preserves historical source material used during Stage 02 only when a local copy can be obtained reliably and redistribution terms are sufficiently clear. Source URLs, provenance and relevance are recorded in `../historical-references.md` whether or not a local copy is present.

- **Josef Prusa `Prusa3` documentation** — upstream repository states **GPLv3**. Selected source documentation is mirrored here with upstream attribution. Upstream license: https://github.com/josefprusa/Prusa3/blob/master/LICENSE.md
- **RepRap Magazine Issue 2** — the archive reports the original license as **CC BY-NC-ND**. It is currently referenced by URL in `../historical-references.md`; no binary PDF copy is stored in this repository at present.
- **Clone Wars / RepRap `Prusai3boxframeconstruction.pdf`** — the document itself states **GFDL**. It is currently referenced by URL in `../historical-references.md`; no binary PDF copy is stored in this repository at present.
- **SpainLabs forum material and other web pages** — referenced by URL only unless explicit redistribution terms justify a local copy.

No absence of a local binary file should be interpreted as lack of provenance: the reference index is the authoritative source catalogue for Stage 02.
