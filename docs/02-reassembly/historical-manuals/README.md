# Historical manuals and references

This directory preserves selected period documentation used as historical source material for Stage 02 reassembly. Only documents whose redistribution terms are sufficiently clear and whose content can be retrieved reliably are stored locally. Other historically relevant sources are indexed by URL in `../historical-references.md` instead of being copied.

## Local source material

- `josefprusa-prusa3-manual.txt` — original `box_frame/doc/manual.txt` from `josefprusa/Prusa3`; GPLv3 upstream. It is a period source and is incomplete in upstream form, ending at the beginning of the Z-axis section.
- `josefprusa-prusa3-dimensions.md` — original rod-dimension notes from the same upstream repository; GPLv3 upstream.
- `LICENSES.md` — redistribution and source-availability notes.

## External-only references

SpainLabs, RepRap Magazine Issue 2, Clone Wars / RepRap PDFs and other period web documentation remain referenced in `../historical-references.md` when a clean local archival copy is not present.

The project-specific manual is maintained separately as `../original-reassembly-manual.md`; repository evidence always overrides a generic historical source when variants disagree.
