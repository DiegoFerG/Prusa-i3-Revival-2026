# Legacy filament archive

This folder documents the surviving legacy filament stock recovered for **Prusa i3 Revival 2026**.

The project deliberately keeps a functional **3 mm / 2.85 mm extrusion stage** so this material can be evaluated and, where practical, consumed before the later conversion to 1.75 mm.

## Rules

- Photograph and catalogue every spool/box before use.
- Record the nominal diameter exactly as labelled: legacy "3.00 mm" and modern 2.85 mm are not assumed identical.
- Dry and test old filament before committing to long prints.
- Never infer material from colour alone.
- Record failures as well as successful settings.
- Abrasive or filled materials require a suitable nozzle.
- Filament that is brittle, chemically degraded or dimensionally inconsistent may be retained for documentation rather than printed.
